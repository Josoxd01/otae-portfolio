# Po-OTAE

Portafolio web premium y administrable para una empresa de arquitectura. Esta base inicial prepara una aplicacion Next.js limpia para evolucionar hacia proyectos, categorias, filtros, detalle de proyecto, contacto y un panel admin.

## Stack inicial

- Next.js con App Router
- TypeScript
- Tailwind CSS
- ESLint
- npm

## Comandos principales

```bash
npm run dev
```

Levanta el servidor de desarrollo.

```bash
npm run lint
```

Ejecuta la verificacion de ESLint.

```bash
npm run build
```

Genera el build de produccion.

## Fases posteriores

Firebase, el panel de administracion, la carga de proyectos, el CMS propio, categorias y filtros se implementaran en fases posteriores. Esta tarea solo define el setup inicial del proyecto.
