# AGENTS.md

Instrucciones para futuros trabajos de Codex en Po-OTAE.

- Mantener TypeScript estricto y respetar la configuracion existente.
- Usar Tailwind CSS para estilos.
- Evitar Bootstrap salvo instruccion explicita.
- Mantener componentes pequenos, legibles y faciles de revisar.
- Priorizar un diseno limpio, minimalista y premium, apropiado para arquitectura.
- No agregar dependencias innecesarias.
- No agregar Firebase hasta que la fase correspondiente lo solicite.
- Antes de finalizar cambios, ejecutar `npm run lint` y `npm run build` cuando aplique.
